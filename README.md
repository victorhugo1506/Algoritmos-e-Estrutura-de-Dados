## ▶️ Como Executar

### Em C

Você precisará de um compilador C instalado (ex: GCC).

```bash
# Compilar
gcc -o questao1 Questão1.c

# Executar
./questao1
```

> No Windows, use `questao1.exe` ao invés de `./questao1`

### Em Python

Você precisará do Python 3 instalado.

```bash
# Executar diretamente
python Questão1.py
```
