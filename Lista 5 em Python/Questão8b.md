Questão 8, Letra B:

O algoritmo de reorganização precisa varrer a lista inteira uma vez para agrupar (compactar) os elementos válidos no início, e depois varrer uma segunda vez de trás para frente inserindo os buracos calculados.Como ambas as varreduras escalam proporcionalmente ao tamanho total do vetor, o tempo de execução exato é linear, resultando em $O(n)$.
