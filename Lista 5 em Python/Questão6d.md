Questão 6, Letra D:

Quando as posições vazias se concentram em uma única extremidade, uma inserção no lado oposto exigirá o deslocamento de quase todo o vetor para empurrar os elementos até os buracos, degradando o tempo de inserção para o pior caso de $O(n)$.Isso pode ser evitado chamando um algoritmo de reorganização periodicamente para redistribuir esses espaços vazios de forma homogênea.
